## 🌟 コンセプト：なぜ DopaTodo なのか？

「やらなきゃいけないのは分かっているのに、どうしてもやる気が出ない…」  
**DopaTodo** は、そんな現代人の **先延ばし・集中力低下・タスク放置** を科学的＆ソシャゲ的アプローチで解決するために誕生しました。

タスクを1つ完了（粉砕）するたびに、**画面が激震し、虹色の紙吹雪とコインが舞い、パチンコ風の報酬確定ルーレットが炸裂**！  
集めたジェムでガチャを引き、神話級の武器や防具を集めてボスを撃破する——**「タスクをこなすのが楽しくてたまらなくなる」究極のドーパミン循環システム** を提供します。

## 🎮 4大コアシステム

```
+-------------------------------------------------------------+
|  [ 📝 ToDo ]   |   [ ⚔️ バトル ]   |   [ 🛡️ 装備 ]   |   [ 🎰 ガチャ ]  |
+-------------------------------------------------------------+
```

### 1. 📝 ToDo粉砕 ＆ 報酬ルーレットシステム
* **💥 タスク粉砕**: 完了ボタンを押した瞬間の爽快なクラッシュ演出＆画面シェイク！
* **🎰 報酬確定ルーレット**: タスク完了時にランダムで大量の 💎 `Dopa Gems` と 🪙 `Coins` を獲得。低確率で **JACKPOT（超大当たり）** が発動！
* **⏱️ 集中タイムアタック**: 3分/5分/15分の集中タイマー発動中は、**報酬が常時1.5倍** にブースト！
* **🔄 定期日課（ルーティン）管理**: 毎日・平日・毎週・毎月のタスクを自動生成。
* **📜 討伐履歴**: 本日粉砕したタスク数・獲得ジェム・獲得コインの推移を一覧確認。

### 2. ⚔️ モンスターボス討伐バトル
* **👾 個性豊かな怠惰モンスターたち**: 「SNSスライム」「二度寝デーモン」「YouTubeドラゴン」など、人間の集中力を奪う悪霊ボスが登場！
* **⚡ オート攻撃 ＋ 連打ドパパンチ**: 装備した武器で毎秒自動攻撃！画面タップ（またはスペースキー連打）で高速攻撃を叩き込める！
* **🔥 ボス発狂 ＆ 撃破ドロップ**: ボスHPが30%以下になると発狂モードへ突入。撃破すると大量のジェムとコインを獲得して次のステージへ！

### 3. 🛡️ 4部位装備ビルド ＆ シリーズセット効果
* **4つの装備スロット**:
  * 🗡️ **メイン武器**: 基礎攻撃力（ATK）を大幅強化
  * 🛡️ **サブ防具/鎧**: 会心ダメージ倍率（CRIT MULT）を底上げ
  * 👑 **頭部ヘルム**: 会心率（CRIT RATE）を上昇
  * 💍 **装飾品/指輪**: タスク完了時の獲得ジェム＆コイン（REWARD UP）を倍増
* **⚡ 総合戦闘力（Total BP）**: 全装備のステータスを合算した総合戦闘力をリアルタイム算出！
* **🌟 シリーズセット効果**:
  * **創世神話シリーズ**: 4箇所装備で会心率100%（全撃確定クリティカル）＋ Gems報酬+30%！
  * **サイバーシリーズ**: 4箇所装備でオート攻撃速度2倍（0.5秒間隔）＋ 会心率+40%！
  * **脳汁ドパシリーズ**: 4箇所装備でルーレットJACKPOT確率2倍 ＆ コイン+50%！
* **🪙 コインによる部位強化**: 集めたコインで装備レベルを上げ、能力値を無限に強化！

### 4. 🎰 神話兵器覚醒ガチャ
* **🔥 単発召喚（100 Gems） ＆ 10連召喚（900 Gems / 1回分お得）**
* **極限の脳汁演出**:
  * **プチュン暗転フリーズ**: UR確定時に画面が完全ブラックアウトし、心音とともに「神話降臨」極太カットインが炸裂！
  * **サプライズ昇格（まだまだァァッ！！）**: カードをめくった瞬間にレアリティが昇格！
  * **★ 限界突破（凸覚醒）**: 被りが出た場合は自動で限界突破し、ステータスが15%ずつ強化！

## 🛠️ 技術スタック ＆ こだわり

外部ライブラリを一切使わず、ブラウザ標準のWeb標準APIのみで構築された**超高速・超軽量・依存ゼロ**のピュアアーキテクチャです。

| 分野 | 採用技術 | 特徴・こだわり |
| :--- | :--- | :--- |
| **言語** | **Vanilla JavaScript (ES Modules)** | フレームワーク不使用（React/Vue/Nextなし）。DOM操作とState管理を軽量モジュール設計で高速動作 |
| **デザイン** | **Vanilla CSS3** | ネオン・サイバーパンク・グラスモフィズム。完全レスポンシブ（PC・タブレット・スマホ最適化） |
| **サウンド** | **Web Audio API** | 音声ファイル（mp3/wav）を1つも読み込まず、**全25種以上の効果音・BGMをオシレーター波形合成でリアルタイム生成**（容量0バイト・遅延0ms） |
| **エフェクト** | **HTML5 Canvas ＋ CSS 3D Transforms** | 虹色コンフェッティ、ゴールドスパーク、カード3D回転、画面激揺れシェイク |
| **PWA** | **Service Worker ＋ Cache Storage** | 完全オフライン動作対応。スマホやPCのホーム画面にアプリとしてインストール可能 |
| **永続化** | **LocalStorage** | 複数セーブスロット対応。いつでもセーブ＆ロード可能 |

## 🚀 クイックスタート

外部パッケージ（npm install など）のインストールは**一切不要**です！  
静的ファイル配信サーバー（またはブラウザで直接）ですぐに動作します。

### 1. リポジトリをクローン
```bash
git clone https://github.com/your-username/dopatodo.git
cd dopatodo
```

### 2. ローカルサーバーを起動
Pythonをお使いの場合：
```bash
# Python 3
python3 -m http.server 8080
```

Node.jsをお使いの場合（npx利用）：
```bash
npx serve .
```

### 3. ブラウザで開く
ブラウザで以下のURLにアクセスしてください：
👉 **`http://localhost:8080/`**

## 📱 スマートフォンでのアプリ化（PWAインストール）

DopaTodoは **PWA (Progressive Web Apps)** に完全対応しています。

* **iOS (Safari)**:
  1. Safariでページを開く
  2. 画面下の **共有ボタン**（四角から矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
* **Android (Chrome)**:
  1. Chromeでページを開く
  2. 画面上部またはメニューの **「アプリをインストール」** または **「ホーム画面に追加」** をタップ

## ⌨️ キーボードショートカット（PC向け）

* **`Space`**: ドパパンチ（モンスター手動強攻撃）
* **`1`**: `📝 ToDo` タブへ瞬時移動
* **`2`**: `⚔️ バトル` タブへ瞬時移動
* **`3`**: `🛡️ 装備` タブへ瞬時移動
* **`4`**: `🎰 ガチャ` タブへ瞬時移動
* **`Enter`**: タスク入力欄で即座にタスク追加

```
dopatodo/
├── index.html        # アプリケーション全体のUI構造（4タブSPA構成）
├── manifest.json     # PWA構成定義マニフェスト
├── sw.js             # Service Worker（オフラインキャッシュ制御）

├── js/
│   ├── app.js        # アプリメインエントリーポイント・タブナビ・状態管理
│   ├── data.js       # 装備データ、モンスターデータ、シリーズセット定義、初期ステート

│   ├── gacha.js      # ガチャ抽選、プチュン暗転、カードめくり、装備付け替え・強化
│   ├── sound.js      # Web Audio API シンセサイザー効果音エンジン

```
